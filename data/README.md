# Data Directory

Most data in this directory is **gitignored** and regenerated by the pipeline (`01_clean_data.do`). This README documents all sources, file layout, and how to reproduce the data from scratch.

## Directory Layout

| Path | Contents | Tracked? | How Obtained |
|------|----------|----------|--------------|
| `acs/` | ACS microdata extracts (one CSV per year) | No | R script `R/api_code.R` via IPUMS API |
| `covid/` | NYTimes county-level COVID CSV | No (small) | Auto-downloaded by `01b_download.do` |
| `demographic/nhgis0031_csv/` | NHGIS time-series county demographics | No | Auto-downloaded by `R/download_nhgis.R` (IPUMS API) |
| `demographic/CAINC1/` | BEA Regional Economic Accounts | No | Auto-downloaded by `01b_download.do` |
| `demographic/bls/` | BLS LAUS county unemployment | No | Auto-downloaded by `R/download_public_data.R` |
| `demographic/dol/` | DOL childcare cost survey | No | Auto-downloaded by `R/download_public_data.R` |
| `demographic/PopCenterCounty_US.csv` | County centroids (center of population) | No | Auto-downloaded by `R/download_public_data.R` |
| `irs/` | IRS SOI migration + county AGI CSVs | No | Auto-downloaded by `01b_download.do` |
| `mapping/` | Shapefiles for maps | **Yes** | Manual / R script |
| `working/` | Intermediate Stata `.dta` files | No | Generated by `01_clean_data.do` |
| `multnomah.xlsx` | Supplementary Multnomah County data | **Yes** | Manual |
| `taxsim_state_codes.csv` | State tax code crosswalk | **Yes** | Manual |

## Source Details

### 1. IPUMS ACS Microdata

- **URL:** https://usa.ipums.org/usa/index.shtml
- **Files:** `acs/acs_YYYY.csv` (one per year, 2012-2024)
- **Pipeline step:** Downloaded by `R/api_code.R` (called from `00_multnomah.do`)
- **Download:** Automatic via IPUMS API (requires API key in `api_codes.txt`)
- **License:** IPUMS Terms of Use (free for research, requires citation)

### 2. IPUMS NHGIS (Demographics)

- **URL:** https://www.nhgis.org/
- **Files:** `demographic/nhgis0031_csv/nhgis0031_ts_nominal_county.csv`
- **Pipeline step:** Imported in `01c_demographics.do`
- **Download:** Automatic via `R/download_nhgis.R` (IPUMS API). Manual fallback: create extract on NHGIS website matching codebook spec.
- **Variables:** Population (total/urban/rural), median household income
- **License:** IPUMS Terms of Use

### 3. IRS SOI Migration

- **URL:** https://www.irs.gov/statistics/soi-tax-stats-migration-data
- **Files:** `irs/countyinflowYYZZ.csv`, `irs/countyoutflowYYZZ.csv`, `irs/stateinflowYYZZ.csv`, `irs/stateoutflowYYZZ.csv` (YY=11-21, ZZ=YY+1)
- **Pipeline step:** Downloaded by `01b_download.do`, cleaned in `01f_irs_migration.do`
- **Download:** Automatic
- **License:** Public domain (IRS)

### 4. IRS SOI County AGI

- **URL:** https://www.irs.gov/statistics/soi-tax-stats-county-data
- **Files:** `irs/YYincyallagi.csv` (YY=11-22; 2012 is `12cyallagi.csv`)
- **Pipeline step:** Downloaded by `01b_download.do`, cleaned in `01g_irs_agi.do`
- **Download:** Automatic
- **License:** Public domain (IRS)

### 5. BEA CAINC1 (Regional Economic Accounts)

- **URL:** https://apps.bea.gov/regional/downloadzip.htm
- **Files:** `demographic/CAINC1/CAINC1__ALL_AREAS_1969_2023.csv`
- **Pipeline step:** Downloaded by `01b_download.do`, cleaned in `01c_demographics.do`
- **Download:** Automatic (ZIP download + extract)
- **Variables:** County population, per-capita personal income
- **License:** Public domain (BEA)

### 6. BLS LAUS (Unemployment)

- **URL:** https://download.bls.gov/pub/time.series/la/la.data.64.County
- **Files:** `demographic/bls/la.data.64.County`
- **Pipeline step:** Verified by `01b_download.do`, cleaned in `01c_demographics.do`
- **Download:** Automatic via `R/download_public_data.R` (or manual fallback from BLS)
- **License:** Public domain (BLS)

### 7. NYTimes COVID-19 Data

- **URL:** https://github.com/nytimes/covid-19-data
- **Files:** `covid/covid_nyt.csv`
- **Pipeline step:** Downloaded by `01b_download.do`, cleaned in `01d_covid.do`
- **Download:** Automatic
- **License:** NYTimes COVID-19 data license (free for research/non-commercial)

### 8. DOL Childcare Cost Data

- **URL:** https://www.dol.gov/sites/dolgov/files/WB/NDCP2022.xlsx
- **Files:** `demographic/dol/NDCP2022.xlsx`
- **Pipeline step:** Verified by `01b_download.do`, cleaned in `01h_auxiliary.do`
- **Download:** Automatic via `R/download_public_data.R` (or manual fallback from DOL)
- **License:** Public domain (DOL)

### 9. Census Age Shares (B01001)

- **Files:** `working/age_shares_county.csv` and `.dta`
- **Pipeline step:** Generated by `R/census_age_shares.R` (called from `01b_download.do`)
- **Download:** Automatic via Census API (requires API key in `api_codes.txt`)
- **Variables:** Share under 24, share 65+, by county (ACS 2015-2019)

### 10. County Centroids (Center of Population)

- **URL:** https://www2.census.gov/geo/docs/reference/cenpop2010/county/CenPop2010_Mean_CO.txt
- **Files:** `demographic/PopCenterCounty_US.csv`
- **Pipeline step:** Cleaned in `01c_demographics.do`
- **Download:** Automatic via `R/download_public_data.R` (Census Bureau source)
- **Variables:** County FIPS, latitude, longitude (2010 census)

## Quick-Start Checklist

To set up the data directory from scratch:

1. **Get API keys:** Place your IPUMS and Census API keys in `api_codes.txt` in the project root (gitignored).

2. **Run R orchestrator:** `source("00_multnomah.R")` or `Rscript 00_multnomah.R`. This will:
   - Download ACS microdata via IPUMS API
   - Download QWI, QCEW data
   - Download BLS LAUS, DOL childcare, county centroids (formerly manual)
   - Download NHGIS demographics via IPUMS API (formerly manual)

3. **Run the pipeline:** Open Stata, set working directory to project root, and run `00_multnomah.do`. This will:
   - Auto-download IRS, BEA, and COVID data
   - Generate all `data/working/*.dta` files

4. **Verify:** Check that `data/working/` contains the expected `.dta` files (ids, demographics_2020, irs_county_gross, acs_migration_file, etc.).

## Gitignore Reference

The following patterns in `.gitignore` exclude data files from version control:

```
data/acs/*.csv, *.rds, *.dat.gz, *.txt, *.xml
data/irs/*.csv
data/working/*
data/demographic/CAINC1/*.csv, *.xml, *.html
data/demographic/bls/*
```

Tracked data files (small, hard to reproduce automatically):
- `data/multnomah.xlsx`, `data/taxsim_state_codes.csv`
- `data/mapping/` (shapefiles)

Note: BLS, DOL, centroids, and NHGIS files are now auto-downloaded by R scripts
and no longer need to be tracked in git.
