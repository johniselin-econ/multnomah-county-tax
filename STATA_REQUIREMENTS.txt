================================================================================
Stata Package Requirements for Multnomah County Tax Analysis
================================================================================

Minimum Stata version: 16.0 (tested on Stata 18/MP)
Stata/MP is recommended for parallel SDID estimation, but not required.

This project requires the following user-written Stata packages before running
the analysis scripts.

--------------------------------------------------------------------------------
REQUIRED PACKAGES
--------------------------------------------------------------------------------

1. reghdfe - Linear regression with high-dimensional fixed effects
   Install: ssc install reghdfe, replace

2. ftools - Fast Stata commands (required by reghdfe)
   Install: ssc install ftools, replace

3. ppmlhdfe - Poisson pseudo-maximum likelihood with HDFE
   Install: ssc install ppmlhdfe, replace

4. sdid - Synthetic Difference-in-Differences
   Install: ssc install sdid, replace

5. sdid_event - Event study post-estimation for SDID
   Install: ssc install sdid_event, replace

6. estout - Export estimation results to LaTeX/Excel
   Install: ssc install estout, replace

7. coefplot - Plot regression coefficients
   Install: ssc install coefplot, replace

8. fre - Frequency tables
   Install: ssc install fre, replace

9. distinct - Count distinct values
   Install: ssc install distinct, replace

10. blindschemes - Color-blind-friendly plot schemes (plotplainblind)
    Install: ssc install blindschemes, replace

11. parallel - Parallel processing for Stata (optional; set use_parallel=0 to skip)
    Install: net install parallel, from(https://raw.github.com/gvegayon/parallel/stable/) replace

--------------------------------------------------------------------------------
ADDITIONAL TOOLING
--------------------------------------------------------------------------------

12. TAXSIM 35 local executable - Revenue microsimulation in 02_revenue.do
    Download: https://taxsim.nber.org/taxsim35/
    Setup: Place the executable on your system PATH, or otherwise make it
           available to Stata's taxsimlocal35 command.
    Note: If TAXSIM is not installed, 02_revenue.do falls back to a simplified
          tax calculator. That fallback is functional, but it is not the paper's
          preferred revenue specification.

--------------------------------------------------------------------------------
QUICK INSTALL (run in Stata)
--------------------------------------------------------------------------------

Copy and paste the following commands into Stata to install all packages:

    ssc install reghdfe, replace
    ssc install ftools, replace
    ssc install ppmlhdfe, replace
    ssc install sdid, replace
    ssc install sdid_event, replace
    ssc install estout, replace
    ssc install coefplot, replace
    ssc install fre, replace
    ssc install distinct, replace
    ssc install blindschemes, replace
    net install parallel, from(https://raw.github.com/gvegayon/parallel/stable/) replace

--------------------------------------------------------------------------------
VERIFICATION
--------------------------------------------------------------------------------

To verify packages are installed correctly, run:

    which reghdfe
    which ppmlhdfe
    which sdid
    which sdid_event
    which estout
    which coefplot
    which fre
    which distinct
    which taxsimlocal35

--------------------------------------------------------------------------------
R PACKAGES (for data download and mapping)
--------------------------------------------------------------------------------

The R scripts also require:
- ipumsr (IPUMS data download)
- sf (spatial data handling)
- tigris (US Census geography)
- tidyverse (data manipulation and visualization)

Install in R with:
    install.packages(c("ipumsr", "sf", "tigris", "tidyverse"))
